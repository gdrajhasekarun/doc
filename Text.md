The invention relates to an AI-driven, intent-aware web application crawler that autonomously discovers, models, and validates user interface workflows to generate maintainable UI automation assets. Unlike conventional test automation frameworks that depend on manually authored scripts, predefined navigation sequences, or hard-coded element locators, the proposed system employs a real browser to dynamically interpret application states, identify interactive elements, and traverse application workflows based on user intent. A deterministic decision engine selectively invokes a Large Language Model (LLM) only when conventional rule-based reasoning and cached knowledge are insufficient, thereby reducing AI inference overhead while maintaining autonomous exploration. The crawler systematically constructs a versioned knowledge graph representing application pages, UI states, transitions, and metadata, which serves as the foundation for automated test generation and future incremental exploration.
A key novelty of the invention lies in its combination of deterministic exploration with adaptive AI reasoning. The system introduces deterministic branch replay to exhaustively explore alternative navigation paths without repeatedly invoking the LLM, thereby improving exploration efficiency and consistency. It further distinguishes multiple application states sharing the same URL using a composite structural fingerprint derived from interactive elements, DOM hierarchy, and layout characteristics, enabling accurate identification of dynamic Single Page Application (SPA) states. The invention also incorporates confidence-based decision making, multi-strategy locator generation, prioritized field-value resolution, adaptive exploration prioritization, and continuous learning from execution feedback, allowing validated decisions to be reused across subsequent crawls while progressively improving automation accuracy and reducing maintenance effort.
The inventive step resides in the integration of these technical mechanisms into a unified autonomous crawling framework that continuously evolves with the target application. Rather than functioning as a conventional AI-assisted testing tool, the invention maintains an incrementally updated knowledge graph capable of detecting application changes, performing delta-based re-crawling, and regenerating resilient Page Object Models (POMs) and test artifacts across multiple programming languages from a single application model. The coordinated use of selective LLM invocation, deterministic branch replay, structural state fingerprinting, adaptive graph evolution, and self-learning feedback establishes a technically improved solution for autonomous UI discovery and test automation, providing enhanced scalability, reduced computational cost, improved test coverage, and significantly lower manual maintenance compared to existing AI-based UI testing approaches.
 


5.	Features/ Steps in the Invention  
Below are the steps/features performed in the invention:
1.	Autonomous Intent-Aware UI Exploration Engine: An AI-driven crawler that autonomously understands application intent and systematically explores all possible UI workflows using deterministic navigation.
2.	Composite UI State Fingerprinting and Knowledge Graph: A mechanism that uniquely identifies dynamic application states and maintains an evolving knowledge graph of UI pages, transitions, and metadata.
3.	Adaptive Decision and Continuous Learning Framework: A confidence-based decision engine that selectively invokes AI, reuses validated decisions, and continuously improves exploration through execution feedback.
4.	Automated Multi-Language Test Artifact Generation: A framework that automatically generates resilient Page Object Models (POMs) and executable test scripts for multiple programming languages from the discovered application model.
